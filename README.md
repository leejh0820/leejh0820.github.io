# leejh0820.github.io

Personal site of Jeonghyun Lee — reinforcement learning for robots, multi-robot exploration, and LLM evaluation.

Live at **[leejh0820.github.io](https://leejh0820.github.io)**

## Structure

```
index.html      page content
style.css       layout, light and dark themes
main.js         theme toggle and the frontier-exploration demo in the header
img/            figures from the ETRI, PPO navigation and HumanoidBench work
fonts/          Schibsted Grotesk (SIL Open Font License, see fonts/OFL.txt)
```

Plain HTML, CSS and JavaScript with no build step. Edit the files and push to `main`; GitHub Pages serves the repository root.

To preview locally:

```bash
python3 -m http.server 8000
```
